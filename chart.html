Two ways to buy recall.
One costs a third as much.

Binary quantization with oversampling, or an unquantized index with a bigger hnsw_ef. Both walk more candidates to catch more of the true neighbours. Only one walks them as single bits.

Result limit
Recall is scored against exact KNN on the same collection, so 1.000 is reachable by construction and nothing here is limited by the embedding model. Both series run at hnsw_ef=300 so the comparison holds graph effort fixed; the green curve sweeps ef from 100 to 512 instead. p95 over 1,000 sequential queries on local gRPC, roughly 0.3 ms of which is transport, with a run-to-run noise floor near 0.2 ms. This is a latency win, not a memory win: rescoring keeps the float vectors resident. Method, raw results and the fuller report: meinsta/qdrant-oversampling-bench.
